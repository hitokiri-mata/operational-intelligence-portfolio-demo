# Public showcase security notes

- No confidential employer source code, datasets, personal information or commercial metrics are published.
- All client names, financial values and people counts are fictional.
- The demo makes no network requests and has no third-party dependencies.
- Do not upload the original internal dashboard, SQLite databases, .env files, OAuth tokens, contracts, payroll data, or application logs to this repo.
- Before deployment, check the public repository contents and the GitHub Pages output.
