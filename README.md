# Operational Intelligence — Independent portfolio showcase

An interactive, static web **demonstration** of product-thinking concepts behind an AI-assisted operational intelligence dashboard. Presented by **César Mata de Ávila** for his technology/product leadership portfolio.

> **Important:** This is a newly created, public-safe recreation of the *experience and interaction patterns* — **not** the source code of any employer's internal system. It uses 100% deterministic **synthetic data**, fictional clients, no third-party libraries, no secret keys, no company identifiers, and no backend. It does not claim to demonstrate live AI inference.

## The problem and product approach

Enterprise service operations commonly span disconnected data about service delivery, staffing, client satisfaction, and economics. The design goal was to make multiple signals understandable in one place, allow exploration by time or client, and clearly distinguish data snapshots from period flows.

## Interactive features

- Filter by year, period, and fictional client, including client search.
- Compare revenue, revenue-weighted contribution margin, staffing, billable resources and pivots/bench.
- Navigate to portfolio and workforce views.
- Adjust a margin target and review automatically generated rule-based decision-support text.
- Open per-client details and export a filtered CSV.
- Layout adapts to mobile screens; no remote assets or tracking.

## Run locally

Open `index.html` in any current desktop or mobile browser. No installation or build step.

## Share on GitHub Pages

1. Create a **new public** GitHub repository named `operational-intelligence-portfolio-demo` (not an existing corporate or unrelated repository).
2. Upload `index.html` and `README.md` to the repository's default branch. Confirm that **no real company files, keys or data** are committed.
3. In repository Settings → Pages, select **Deploy from a branch**, `main`, `/ (root)` and Save.
4. Wait for GitHub to report the active deployment; copy the **actual URL shown by GitHub**. Do not assume that a guessed address works.
5. Test the public link in a private browsing window and on mobile before submitting the application.

## Data and privacy

The demo's data is generated in memory from constant formulas for four fictional companies. No uploads, downloads from external networks, cookies, API calls, live AI services, or personal data are required. CSV export only saves your chosen synthetic summary to your own device.
